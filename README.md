# منظومة تقارير الأمن — G-Tracker

تطبيق PWA موحّد (أندرويد + آيفون) يجمع نظام الصلاحيات الأربعة مع ميزات SOS Guard.

## التشغيل

```bash
npm install
node server.js
```

الخادم يعمل على المنفذ `3000`.

## الأدوار

| الدور | اسم المستخدم | كلمة المرور |
|---|---|---|
| أوفيسر | `officer` | `1234` |
| مشرف | `supervisor` | `1234` |
| قائد | `commander` | `1234` |
| حارس | `guard1` | `1234` |

## الميزات

- سلسلة التقرير: حارس ← قائد ← مشرف ← أوفيسر مع مصفوفة صلاحيات
- مناوبة: جولات فحص مع QR، قائمة فحص، حوادث (ملاحظة/طارئ)
- تقرير PDF عربي/إنجليزي + مشاركة واتساب
- تنبيهات فورية للأوفيسر عند أي تغيير إعدادات أو حادث طارئ
- لوحة إحصائيات وسجل تعديلات
- نسخ احتياطي واسترجاع
